# Корпоративные стандарты разработки и UI проекта ЦОПП (COPP-RAS)

Данный документ обязателен к соблюдению всеми разработчиками и AI-агентами (Antigravity/Gemini) при добавлении или изменении интерфейсов системы.

---

## 1. Архитектура таблиц и реестров в панели администратора

Все таблицы, списки и реестры в админ-панели (`/admin`) должны иметь идентичный внешний вид и разметку (как в реестре пользователей `user_list.html` и реестре объявлений `announcements_tabs.html`).

### 1.1 Контейнер реестра (`.table-registry-card`)
- **Ширина и центрирование**: Таблица должна быть заключена в блок с классом `.table-registry-card` (`max-width: 1250px; margin-left: auto; margin-right: auto;`).
- **Скругления и тени**: `border-radius: 14px; border: none; box-shadow: 0 2px 8px rgba(0,0,0,0.04); overflow: hidden;`.
- **Запрет «блоков в блоке»**: Во вкладках админки (`admin_dashboard.html`, `admin_tabs/*.html`) запрещено оборачивать содержимое вкладки во внешний `<div class="card p-4">`, если внутри используется `.table-registry-card`. Карточка реестра должна быть самодостаточным верхнеуровневым контейнером вкладки.

### 1.2 Шапка реестра (`.table-registry-header`)
- Верхняя панель карточки реестра оформляется классом `.table-registry-header` с разделителем `border-bottom: 1px solid var(--border-color);`.
- Доступен готовый Jinja-макрос:
  ```jinja2
  {% from 'macros/registry.html' import render_registry_header %}
  {{ render_registry_header(
      title='Реестр записей',
      subtitle='Управление и мониторинг записей',
      total_count=items|length,
      filtered_count=items|length,
      create_btn_text='Создать запись',
      create_modal_target='#createItemModal'
  ) }}
  ```

### 1.3 Стилизация таблицы (`.table`)
- Классы: `<table class="table table-hover align-middle mb-0">`.
- Шапка `<thead>`: серый приглушенный текст (`color: var(--text-muted); font-weight: 600; font-size: 0.75rem; text-transform: uppercase; letter-spacing: 0.5px;`).
- Строки `<tbody>`: легкий hover-эффект (`rgba(13, 71, 161, 0.02)`), разделители ячеек без грубых рамок.
- Подвал/пагинация: нижняя полоса с `border-top`, прижата к нижнему краю карточки с закруглениями.

## 2. Цветовая палитра и элементы управления

### 2.1 Основные цвета
- **Основной корпоративный цвет (Brand Primary)**: `#00334e` (глубокий темно-синий ЦОПП).
- **Кнопки действий**:
  - Основная: `.btn.btn-copp` (`background: #00334e; color: #fff; border-radius: 8px; font-weight: 500;`).
  - Второстепенная / контурная: `.btn.btn-outline-copp` (`border-color: #00334e; color: #00334e;`).
  - Нейтральная / отмена: `.btn.btn-light` или `.btn.btn-secondary`.

### 2.2 Семантические статусы (Контекстные цвета)
Используются строго по назначению:
- **Инфо / Обычный**: Navy `#00334e` (`.badge-status-info`, фон `rgba(0, 51, 78, 0.08)`).
- **Предупреждение / Срок подходит**: Янтарный `#b45309`, фон `#fffbeb`, рамка `#fde68a` (`.badge-status-warning`).
- **Срочно / Ошибка / Просрочено**: Красный `#dc2626`, фон `#fef2f2`, рамка `#fecaca` (`.badge-status-danger`).
- **Успех / Активно / Сдано**: Зеленый `#16a34a`, фон `#f0fdf4`, рамка `#bbf7d0` (`.badge-status-success`).
- **Цвет `#ff0072`**: Строго пасхалка! Зарезервирован исключительно для карточек доработки отчетов. Запрещено использовать для стандартных элементов, бейджей или кнопок.

## 3. Запрет эмодзи (Строгое правило)

- **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** использовать unicode-эмодзи (такие как ℹ️, ⚠️, 🚨, 📅, 👥, 🔔, ✅, ❌ и т.д.) в:
  - бейджах статусов,
  - выпадающих списках `<select>` (в `<option>`),
  - заголовках таблиц и карточек,
  - кнопках и ссылках.
- **Вместо эмодзи** ВСЕГДА используются векторные иконки **Bootstrap Icons**:
  - Пример: `<i class="bi bi-info-circle me-1"></i>`, `<i class="bi bi-exclamation-triangle me-1"></i>`, `<i class="bi bi-bell me-1"></i>`.

## 4. Форматирование дат

- Все даты и время отображаются в едином корпоративном формате:
  - С временем: `{{ item.created_at.strftime('%d.%m.%Y %H:%M') }}` (например, `25.09.2026 14:30`).
  - Только дата: `{{ item.date.strftime('%d.%m.%Y') }}` (например, `25.09.2026`).
